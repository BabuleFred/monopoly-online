# Монополия (русская версия) — мультиплеер в браузере

## Цель
Веб-игра «Монополия» (русская локализация Hasbro) для игры с друзьями через интернет. Сервер запускается на одном ПК (Windows), телефоны подключаются через браузер по публичной ссылке (ngrok-туннель).

## Решённые вводные
- **Платформа:** веб-игра в браузере (телефоны — клиенты).
- **Хост:** этот компьютер (Windows), доступен и с интернетом во время игры.
- **Доступ:** ngrok-туннель → публичная HTTPS-ссылка, телефоны открывают её в браузере.
- **Игроков:** 2–6.
- **Поле:** классическое квадратное (40 клеток по периметру), отрисовка на Canvas.
- **Локализация:** русская версия Hasbro — улицы (ул. Мира, ул. Пушкинская и т.д.), 4 вокзала, 2 коммунальных предприятия (Электростанция, Водопроводная станция), карточки Шанс / Общественная казна.
- **Правила:** полная классика — покупка/продажа, аренда, дома/отели, тюрьма (3 способа выхода), аукционы, обмен между игроками, банкротство, налоги, карточки.
- **Автосохранение:** в файл, восстановление после перезапуска сервера.
- **Лобби:** хост создаёт комнату с уникальным кодом, игроки входят по коду + имя.

## Архитектура

Вся игровая логика и состояние — на сервере. Клиент только отображает состояние и отправляет действия. Это защищает от читерства и держит клиентов лёгкими.

```
┌─────────────────┐         WebSocket          ┌──────────────────┐
│  Браузер телефона│  ←── JSON сообщения ──→  │   Node.js сервер   │
│  (HTML/Canvas/JS)│                          │  (игровая логика)  │
│  только отображает│                         │   ↓ сохраняет      │
│  и отправляет действия│                     │  game-state.json   │
└─────────────────┘                          └──────────────────┘
        ↑                                          ↑
   ngrok туннель (https)                     этот ПК (Windows)
   телефоны с вахты заходят по ссылке
```

### Технологии
- **Бэкенд:** Node.js + `ws` (WebSocket). Без фреймворков.
- **Фронтенд:** чистый HTML/CSS/JS, поле — HTML Canvas.
- **Туннель:** ngrok.
- **Сохранение:** JSON-файл на диске.

### Ключевые решения
- Множественные комнаты — можно играть несколькими компаниями параллельно.
- Состояние каждой комнаты хранится в памяти сервера + автосейв в `game-state.json` (debounce 500мс после каждого действия, меняющего состояние). Дополнительно — `saveImmediately()` при `SIGINT`/`SIGTERM`, чтобы не терять последние ходы при остановке сервера.
- WebSocket-сообщения — JSON с полями `type` и `payload`.
- Сервер рассылает полное состояние комнаты всем игрокам после каждого действия (состояние маленькое, ~5–10 КБ на комнату).
- **Рекконект:** клиент хранит `code`, `playerId`, `token` в `localStorage`. При разрыве WS-соединения клиент автоматически пытается переподключиться и отправляет `{type:"reconnect", payload:{code, playerId}}`. Сервер находит комнату (в памяти или восстановленную из файла), привязывает новый WS-объект к старому `playerId`, высылает актуальный `gameState`.
- **AFK-таймауты:** сервер держит ping/pong по WebSocket. Если игрок оффлайн >60 сек во время своего хода (фаза `roll` или выбор купить/аукцион), ход автоматически завершается: авто-отказ от покупки клетки → аукцион либо авто-пас, `endTurn`.

## Поток игры

### Запуск
1. Хост открывает ссылку → «Создать игру» → вводит имя, выбирает фишку → получает код комнаты.
2. Игроки открывают ссылку → «Войти в игру» → вводят код + имя + фишку.
3. Хост видит список зашедших → «Начать игру».
4. Сервер перемешивает порядок хода, раздаёт по 1500₽, игра начинается.

### Фазы хода игрока
```
[roll] → игрок бросает кубики
   │
   ├─ дубль → после действия можно бросить снова (макс. 3 дубля подряд = тюрьма)
   │
[move] → фишка двигается на выпавшее значение
   │
   └─ прошёл Старт → +200₽
   │
[land] → что на клетке:
   ├─ Старт/Парковка/Просто посетитель → ничего
   ├─ Налог → заплатить 200₽ (Подоходный) или 100₽ (Роскошь)
   ├─ Свободная улица/вокзал/коммуналка → предложить купить или аукцион
   ├─ Чужая собственность → заплатить аренду
   ├─ Шанс/Общественная казна → вытянуть карточку
   ├─ Арест (поз. 30) → в тюрьму: сервер принудительно ставит `position=10`, `inJail=true` и завершает ход (`endTurn`). Игрок не может купить «Малую Бронную», просто «пролетев» мимо.
   └─ Тюрьма (поз. 10) → если inJail, логика выхода
   │
[action] → необязательные действия в любое время хода:
   ├─ Построить/продать дом (нужна монополия цвета)
   ├─ Заложить/выкупить собственность
   ├─ Предложить обмен другому игроку
   ├─ Разыграть карточку «освободиться из тюрьмы»
   │
[end] → «Завершить ход» → переход к следующему игроку
```

### Тюрьма (3 способа выхода)
1. Бросить дубль в свой ход (до 3 попыток) → двигаешься на выпавшее, дубль не даёт повторный бросок.
2. Заплатить 50₽ до броска → бросаешь и двигаешься.
3. Использовать карточку «Освобождение из тюрьмы» → бесплатно.
- После 3 неудачных попыток → платишь 50₽ и двигаешься на последний бросок.

### Аренда
- **Улица:** базовая; удваивается при владении всей группой без домов; с домами — по `rent[houses]`.
- **Вокзал:** 25₽/50₽/100₽/200₽ за 1/2/3/4 вокзала.
- **Коммуналка:** 4× кубики за 1, 10× кубики за 2.

### Дома и отели
- Строить только при владении всей группой.
- Равномерное строительство (нельзя 2-й дом, пока во всей группе нет по 1).
- Максимум 4 дома + 1 отель на клетку.
- Продажа домов банку за 50% цены.
- Лимит строений в банке: `room.bankHouses` (32), `room.bankHotels` (12). При `buildHouse` сервер проверяет наличие. Если дома кончились (0) — строить нельзя, пока кто-то не продаст или не улучшит до отеля. При строительстве отеля банку возвращаются 4 дома, забирается 1 отель.

### Аукцион
- При отказе купить выпавшую собственность → автоматический аукцион.
- Все игроки (включая отказавшегося) участвуют.
- Минимальная ставка 10₽, каждый повышает; пас выбывает из аукциона.
- Победитель платит банку, получает собственность.
- Пока `room.auction !== null`, сервер блокирует все действия, кроме `bid` и `passBid`. Аукцион — интерактивное событие для всех игроков одновременно, прерывающее пошаговый ход.

### Обмен между игроками
- Игрок предлагает обмен: свои собственности/деньги ↔ чужие.
- Второй игрок видит предложение → принимает / отклоняет / контр-предложение.
- **Заложенное имущество можно передавать.** При переходе права владения свойство остаётся `mortgaged: true`. Новый владелец должен сразу выбрать: либо снять залог (заплатить стоимость + 10%), либо оставить в залоге (заплатить банку 10% стоимости). Сервер обрабатывает этот выбор при принятии обмена.

### Банкротство
- Если игрок должен больше, чем имеет (с учётом продажи домов и заложения).
- Все его собственности переходят кредитору (или банку, если долг банку).
- Игрок выбывает.

### Карточки Шанс / Общественная казна
Полные колоды русской версии (по 16 карточек), включая:
- Денежные («Получите 50₽», «Заплатите 40₽ за каждый ваш дом…»).
- Перемещения («Отправляйтесь на Старт», «Бегите в тюрьму», «Перейдите на ул. Пушкинскую»).
- «Освобождение из тюрьмы» (по 1 в каждой колоде).
- Ремонт («Общему ремонту» — платите за дома/отели).

## Автосохранение
- После каждого изменения состояния → `persistence.js` сериализует все комнаты в `data/game-state.json` (debounce 500мс).
- При старте сервера → восстанавливает комнаты из файла, переподключает игроков по коду комнаты.
- `process.on('SIGINT')` и `process.on('SIGTERM')` → `persistence.saveImmediately()` (синхронная запись), чтобы последние ходы не терялись при остановке сервера.

## Правила в игре
- В игровом интерфейсе есть кнопка «Правила» (доступна всегда: в лобби и во время игры).
- Открывает модальное окно/экран с полным текстом правил на русском:
  - Цель игры, подготовка, ход игры.
  - Бросок кубиков, дубль, три дубля подряд → тюрьма.
  - Покупка собственности, аренда, монополия (удвоение аренды).
  - Дома и отели, равномерное строительство, лимит строений (32 дома, 12 отелей).
  - Вокзалы и коммуналки (формулы аренды).
  - Тюрьма: 3 способа выхода, 3 попытки.
  - Карточки Шанс / Общественная казна.
  - Налоги (Подоходный 200₽, Роскошь 100₽), Старт (+200₽).
  - Аукцион при отказе от покупки.
  - Обмен между игроками (в т.ч. передача заложенного).
  - Залог собственности (получение 50% от банка, выкуп +10%).
  - Банкротство и конец игры.
- Текст правил хранится в `public/rules.html` (статика), открывается из `index.html` без обращения к серверу.
- Кнопка «Правила» доступна всем игрокам в любой момент, не прерывая ход.
